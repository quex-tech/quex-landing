how
QUEX works

Executor registration

  • 01

    Launch oracle codebase
    within Quex VM

  • 02

    Quex VM is a minimalistic, fully encrypted VM with no input devices, secured by Intel TDX

  • 03

    Executor code generates fresh
    private key, that never leaves this VM

  • 04

    Generate signed quote with
    a corresponding public key

  • 05

    Verify and register
    quote on-chain

Executor pools

  • 01

    Executors with the same codebase
    combine within pools

  • 02

    Dapps register their data flows
    and callbacks

  • 03

    Dapps makes requests
    to executor pools

  • 04

    Certified responses are transported
    on-chain and initiate the data flow

  • 05

    Reward is paid for the executor
